# Ultra TV AI

Личный каталог сериалов для телевизионных приставок МТС/KION, компьютера и смартфона.

## Возможности прототипа v0.6

- Общая лента новых серий с сортировкой по дате первого появления в каталоге.
- Фильтры по жанрам, поиск сериалов, отметки просмотренного.
- Начальная подборка из 25 сериалов.
- Данные о сериалах и эпизодах из [TVmaze](https://www.tvmaze.com/api); для обновления требуется интернет.
- Отметки о русской озвучке (LostFilm, дубляж и др.) пока **ручные** и не подтверждают наличие конкретного перевода.
- **Одно нажатие:** карточка сериала или эпизода сразу открывает окно просмотра — предварительного окна с выбором серии больше нет.
- **Внутри плеера** есть выбор сезона и серии. Если выбран встроенный плеер всего сериала со своим переключателем, наши дополнительные элементы сворачиваются.
- При наличии привязанного источника видео открывается сразу. **Подключено 64 эпизода в трёх сериалах**: Гангстерленд (18), Укрытие (30), Фоллаут (16), с публичными встроенными плеерами RUTUBE.
- Открытие постера выбирает новейшую серию с доступным плеером, если подходящих видео несколько. При открытии эпизода из ленты сохраняется запрошенная серия.
- Поддерживаются встраиваемые iframe-плееры: можно добавить готовый HTML-код iframe или прямой embed-URL (для поддерживаемых сервисов обычные ссылки преобразуются в embed). Один источник можно назначить на **весь сериал**, если внешний плеер содержит собственное меню сезонов и серий.
- Управление ссылками спрятано в **Настроить источники**. Также доступны MP4/WebM, HLS (.m3u8) и открытие внешней страницы отдельно. Ссылки вводятся только при первоначальной настройке.
- Видеоплеер запоминает позицию просмотра и отмечает серию просмотренной при завершении. Ссылки и позиции сохраняются локально в браузере и входят в JSON-резервную копию.
- HLS использует [hls.js](https://github.com/video-dev/hls.js) при необходимости; нужен доступ к CDN, а источники с DRM/CORS-ограничениями не заработают без разрешений владельца видео.
- Избранное и история просмотра хранятся локально в браузере и **пока не синхронизируются** между устройствами.

## Публикация на Cloudflare Pages

1. Cloudflare Dashboard → **Workers & Pages** → **Create application** → **Pages** → **Connect to Git**.
2. Выберите GitHub и репозиторий `0111anna77-wq/ultra-tv-ai`.
3. Production branch: `main`.
4. Framework preset: `None`; build command: **пусто**; output directory: `/` (корень проекта).
5. Сохраните и запустите публикацию. После настройки следующие изменения ветки `main` публикуются автоматически.

Сайт — статический HTML/CSS/JavaScript. `_headers` и `robots.txt` ограничивают поисковую индексацию, **но не защищают сайт паролем**.

## Следующие этапы

- Автоматическая проверка доступности озвучки на разрешённых источниках.
- Синхронизация избранного между приставками и телефоном.
- Лёгкий Android TV браузер и голосовое управление с телефона.

Не размещайте в репозитории API-ключи или личные секреты.
**Ограничение:** TVmaze не предоставляет ссылки на видео. Для остальных сериалов источники пока не найдены. Видеоплееры RUTUBE могут становиться недоступными, менять географические ограничения или удаляться. Эта версия не обходит DRM и другие ограничения.

## Справочник источников

`watch-options.json` хранит централизованный список прямых ссылок на плееры по ключу `show:SxxExx`, например `mobland:S01E01`. Плееры добавлены для 64 видео с RUTUBE, проверенных 16 ноября 2026: `is_paid=false`, `is_deleted=false`, `is_licensed=true` по публичному API платформы, продолжительность больше 20 минут. Это **метаданные самой RUTUBE**, а не независимая проверка прав на сериал.

Встраивание для 1-й серии «Гангстерленда» и фактическое воспроизведение в Chrome на домене Ultra TV проверены. Для остальных 63 видео подтверждены наличие записи и готового embed URL, а также загрузка плееров в тестах для «Укрытия» и «Фоллаута» — не каждый ролик был воспроизведён полностью. Обозначение «дубляж» или «русская озвучка» основано на названиях видеозаписей; языковые дорожки на слух не проверены.

Реестр подгружается с сайта при каждом запуске, поэтому новые источники можно добавлять через GitHub без ручной настройки на устройствах. Пользовательские источники и история остаются локальными.
