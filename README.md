# Ultra TV AI

Личный каталог сериалов для телевизионных приставок МТС/KION, компьютера и смартфона.

## Возможности прототипа v1.2

- Общая лента новых серий с сортировкой по дате первого появления в каталоге.
- **Отметки времени:** в окне просмотра можно вручную ввести минуту остановки (например `24:35` или `1:02:15`) и нажать «Запомнить». На главной «Вернуться к просмотру» появится эта минута. Сохранение не перезагружает iframe, не перематывает Initem и не выдаётся за автоматический прогресс. Данные сохраняются только в браузере и в JSON-резервной копии.
- **Android TV APK, прототип:** исходники и автоматическая облачная сборка в ветке `feature/android-tv-app`, папка `android-tv/`. APK запускает этот сайт в самостоятельном WebView-приложении, поддерживает ТВ-пульт и полноэкранный режим. Аппаратная совместимость с KION DTP2162 не подтверждена, и пользовательские данные WebView пока **не синхронизируются** с веб-браузером. Для этого нужен облачный профиль (Cloudflare Worker + D1 или аналог) и безопасное сопряжение устройств.
- **Вернуться к просмотру:** на главной показываются до 6 недавно открытых сериалов с последней выбранной серией. Запись ведётся при открытии и переключении серий. История ограничена 40 сериалами, хранится в этом браузере и включается в JSON-резервную копию.
- **Отметки «Просмотрено»:** кнопку можно нажать прямо в общей ленте, без открытия карточки или плеера. Фильтр «Только непросмотренные» работает по этим отметкам; открытие стороннего iframe само по себе серию просмотренной не делает.
- **Подписки на сериалы:** в «Мой каталог» кнопка «✓ Отслеживается · убрать» отключает подписку на обновления (сериал **не удаляется**). Теперь при отключении каталог автоматически показывает все карточки, включая скрытые, и выдаёт уведомление с кнопкой «↶ Вернуть в мои»; пользователь может в любой момент включить «Показать все, включая скрытые». Кнопка «＋ Следить за сериалом» возвращает сериал в ленту. История просмотра, выбранные озвучки и отметки времени сохраняются.
- **Ограничение внешнего плеера:** раздел «Вернуться к просмотру» запоминает **последнюю выбранную серию в Ultra TV**, но не позицию просмотра в Initem и не гарантирует, что внешняя страница откроет именно нужную серию. Точный таймкод и дорожку сторонний iframe не сообщает сайту.

- Фильтры по жанрам, поиск сериалов, отметки просмотренного.
- Начальная подборка из 25 сериалов.
- Данные о сериалах и эпизодах из [TVmaze](https://www.tvmaze.com/api); для обновления требуется интернет.
- **LostFilm RSS автоматически:** данные об опубликованных эпизодах обновляются без включённого ПК. Новые выпуски попадают в отдельный блок ленты и отмечаются у совпавших эпизодов. Другие студии пока отмечаются вручную.
- **Одно нажатие:** карточка сериала или эпизода сразу открывает окно просмотра — предварительного окна с выбором серии больше нет.
- **Внутри плеера** есть выбор сезона и серии. Если выбран встроенный плеер всего сериала со своим переключателем, наши дополнительные элементы сворачиваются.
- При наличии привязанного источника видео открывается сразу. **Подключено 64 эпизода в трёх сериалах**: Гангстерленд (18), Укрытие (30), Фоллаут (16), с публичными встроенными плеерами RUTUBE.
- **Автопоиск для остальных сериалов:** если TVmaze возвращает IMDb ID, Ultra TV автоматически предлагает дополнительный Initem-плеер по этому ID. Он появляется без ручного добавления ссылки или API-ключа. Для этих сериалов это только *попытка поиска*: наличие конкретного эпизода и озвучки ещё не проверено. Старые данные TVmaze без IMDb ID обновляются при следующей синхронизации.
- Для «Гангстерленда», «Укрытия» и «Фоллаута» **Initem β теперь выбирается по умолчанию** и показывает меню озвучек (в ответах сервиса перечислены LostFilm, HDRezka, NewComers, Red Head Sound и другие). **RUTUBE сохранён в списке как запасной источник**. Если пользователь ранее вручную выбирал другой плеер для серии, сохранённый выбор сохраняется.
- В облачном Chrome (география США) плеер Initem показывает **региональную блокировку**, однако пользователь сообщил, что у него воспроизведение работает. Работу именно LostFilm на всех сериях это не подтверждает.
- У релизов RSS, для которых нет подтверждённого плеера на конкретную серию, появляется кнопка «Проверить новую серию в Initem». Она открывает каталог внутри стороннего плеера, **не обещая**, что новый эпизод уже доступен.
- Открытие постера выбирает новейшую серию с доступным плеером, если подходящих видео несколько. При открытии эпизода из ленты сохраняется запрошенная серия.
- Поддерживаются встраиваемые iframe-плееры: можно добавить готовый HTML-код iframe или прямой embed-URL (для поддерживаемых сервисов обычные ссылки преобразуются в embed). Один источник можно назначить на **весь сериал**, если внешний плеер содержит собственное меню сезонов и серий.
- Управление ссылками спрятано в **Настроить источники**. Также доступны MP4/WebM, HLS (.m3u8) и открытие внешней страницы отдельно. Ссылки вводятся только при первоначальной настройке.
- Видеоплеер запоминает позицию просмотра и отмечает серию просмотренной при завершении. Ссылки и позиции сохраняются локально в браузере и входят в JSON-резервную копию.
- HLS использует [hls.js](https://github.com/video-dev/hls.js) при необходимости; нужен доступ к CDN, а источники с DRM/CORS-ограничениями не заработают без разрешений владельца видео.
- Избранное, выбранные серии, отметки просмотренного и история сохраняются в браузере и **пока не синхронизируются** между устройствами.

## Публикация на Cloudflare Pages

1. Cloudflare Dashboard → **Workers & Pages** → **Create application** → **Pages** → **Connect to Git**.
2. Выберите GitHub и репозиторий `0111anna77-wq/ultra-tv-ai`.
3. Production branch: `main`.
4. Framework preset: `None`; build command: **пусто**; output directory: `/` (корень проекта).
5. Сохраните и запустите публикацию. После настройки следующие изменения ветки `main` публикуются автоматически.

Сайт — статический HTML/CSS/JavaScript. `_headers` и `robots.txt` ограничивают поисковую индексацию, **но не защищают сайт паролем**.

## Автоматическое отслеживание LostFilm

- GitHub Actions: `.github/workflows/lostfilm-releases.yml` проверяет официальную RSS-ленту `https://www.lostfilm.tv/rss.xml` в **:17 и :47 каждого часа UTC**.
- Скрипт `scripts/update_lostfilm.py` отбирает записи `SxxEyy`, сохраняет **только метаданные выпуска** (сериал, сезон, серия, дата и ссылка на описание) в `releases.json`. Фильмы, спецвыпуски и записи без номера эпизода не записываются как новые серии.
- При сетевой ошибке или изменении формата RSS скрипт завершает работу с ошибкой, **не обнуляя старые выпуски**. Запись в GitHub обновляется только при изменении содержания.
- Сайт загружает `releases.json` при открытии и каждые 15 минут, когда вкладка активна. Показываются только релизы тех сериалов, которые включены в каталог пользователя. Для дополнительных сериалов нужны сопоставимые русские или английские названия.
- Если эпизод есть и в TVmaze, появляется отметка «Озвучка LostFilm опубликована (плеер не проверен)». Ссылка на **подключённый** видеоплеер показывается отдельно и только если он реально привязан к эпизоду в `watch-options.json` или вручную.
- **Важно:** RSS LostFilm **не выдаёт iframe-плеер и не подтверждает видеоисточник**. Новый релиз LostFilm нельзя автоматически выдавать за подключённый источник с этой дорожкой. Initem β возвращает варианты дорожек в своём плеере, но не гарантирует наличие новой серии и не даёт нам подтверждённый способ автоматически выбрать LostFilm из внешнего iframe. Для надёжного выбора и автоматического подключения новых переводов всё ещё нужен источник с документированным разрешённым API.
- Публичные GitHub Actions могут быть задержаны, отключены в настройках репозитория или автоматически приостановлены GitHub после 60 дней без активности. Успешный первоначальный запуск подтверждён; дальнейший график зависит от GitHub.

В RSS обнаружены 13 записей с номером серии. Например, **«Гангстерленд» S02E09** опубликован LostFilm; в RUTUBE-реестре пока есть S02E01–S02E08, поэтому новый эпизод показывается как релиз озвучки без ложного утверждения о доступности плеера.

## Справочник источников

`watch-options.json` хранит централизованный список прямых ссылок на плееры по ключу `show:SxxExx`, например `mobland:S01E01`. Плееры добавлены для 64 видео с RUTUBE, проверенных 16 ноября 2026: `is_paid=false`, `is_deleted=false`, `is_licensed=true` по публичному API платформы, продолжительность больше 20 минут. Это **метаданные самой RUTUBE**, а не независимая проверка прав на сериал.

Встраивание для 1-й серии «Гангстерленда» и фактическое воспроизведение в Chrome на домене Ultra TV проверены. Для остальных 63 видео подтверждены наличие записи и готового embed URL, а также загрузка плееров в тестах для «Укрытия» и «Фоллаута» — не каждый ролик был воспроизведён полностью. Обозначение «дубляж» или «русская озвучка» основано на названиях видеозаписей; языковые дорожки на слух не проверены.

Реестр подгружается с сайта при каждом запуске, поэтому новые источники можно добавлять через GitHub без ручной настройки на устройствах. Пользовательские источники и история остаются локальными.

**Проверка 16 ноября 2026:** облачный HTTP-запрос получил от Initem корректные страницы «Гангстерленда», «Укрытия», «Фоллаута» и списки озвучек, включая LostFilm. Но облачный браузер со стороны США получил «Видео недоступно для вашего региона: US». Это **не подтверждённый бесплатный просмотр**, а экспериментальная альтернатива для проверки в другом регионе. На опубликованном сайте проверены 13 записей RSS и два пункта выбора источника («RUTUBE», «Initem β») для «Гангстерленда».
