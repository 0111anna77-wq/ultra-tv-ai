# Ultra TV — запасные источники плеера (исследование 19.11.2026)

**Только исследование. Ничего не подключать без отдельного тестирования; текущий Initem β сохранить.** Публикация Ultra TV 0.23 не меняется.

## Почему это актуально
На 19.11.2026 `api.initem.ws` не проходит TLS handshake (curl 35), DNS его родительского домена указывает на `ns1.lander.d.parity.domains` / `ns2.lander.d.parity.domains` (серверы парковки). Это похоже на проблему домена/оператора; восстановление возможно, но не гарантировано. Подробности в `ULTRA_TV_V023_HANDOFF.md`.

## Технический профиль Ultra TV
- `tv.js` генерирует Initem iframe через `https://api.initem.ws/embed/imdb/tt...`, а `availableSources()` строит список из `site/watch-options.json`.
- `site/tv-catalog.json` содержит **25 шоу**; среди ID-полей есть **IMDb**, но **нет Кинопоиск ID**. Для кандидата, принимающего только КП-ID, понадобится сопоставление (и корректная проверка, что это та же версия сериала).
- В `watch-options.json` для `mobland` настроен только Initem; других источников в конкретном сериале сейчас нет.
- Обязательные проверки: качество и наличие русских озвучек (приоритет LostFilm), сезон/серия, воспроизведение на Android WebView KION, работа с VPN, реклама, публичные iframe-разрешения, сохранение позиции/переход на заданную серию. HTML HTTP 200 не доказывает, что видео действительно играет.

## Проверенные кандидаты
1. **APIPlayer.ru** — https://apiplayer.ru/ — публичная документация iframe по IMDb или TMDB, сезону, серии; start/t для секунд, resume, много языков субтитров, заявлен отказоустойчивый режим. Проверка с User-PC: `/embed/tv/tt0212671/1/2` **HTTP 200**, HTTPS нормальный. Наиболее быстрый *технический* пробный iframe, без новой таблицы ID. **Минус:** не подтверждены русские озвучки или наличие конкретных сериалов; на странице акцент на субтитрах, а не студиях. Потоки, лицензии и фактическая работа в KION не протестированы. Источник: https://apiplayer.ru/.
2. **KinoBox, агрегатор** — https://kinoboxtv.tatnet.app/ (отдельная развернутая копия, **не путать с kinobox.tv**). У публичной страницы есть варианты embed/JS, параметры IMDb или КП, собирает Collaps/Alloha/Kodik/другие. На User-PC `kinoboxtv.tatnet.app` **HTTP 200**; зато предполагаемый upstream `https://kinobox.tv/` и `https://kinobox.tv/embed/#301` отдаёт **HTTP 404**. В других проектах сообщается, что основной API Kinobox закрыт с 01.07.2026. Значит готовый пример с `kinobox.tv` **нельзя считать рабочим**; нужен ручной тест именно конкретной копии, уточнение API, лицензий и качества источников. Документация копии: https://kinoboxtv.tatnet.app/; ограничение: https://github.com/Lifailon/LibreKinopoisk.
3. **Vibix** — https://vibix.tv/ — работающий сайт (**HTTP 200** на User-PC), проект утверждает выбор русских озвучек, API/iframe, поиск по IMDb/КП. На сайте опубликованы условия **от 1000 уникальных посетителей/сутки, 80% запусков РФ**, подключение через Telegram; вероятно не подходит для личного малопосещаемого Ultra TV без отдельного согласия провайдера. Реклама интегрирована. Документация: https://dev.vibix.org/roadmap.html, https://vibix.tv/.
4. **Alloha TV** — https://allohatv.cc/ (**HTTP 200**) — готовый iframe, сезоны, библиотека и партнёрская модель с рекламой. Нужно согласовать разрешение/доступ к API, проверить наличие LostFilm и подходящую лицензию. Сайт ориентирован на вебмастеров, не гарантирует бесплатный частный iframe. https://allohatv.cc/.
5. **Kodik** — отдельный сервис от одноимённого ИИ-редактора; API для поиска по IMDb/КП, сериалов и студий озвучки, выдаёт `player_link`, особенно известен по аниме. `https://kodik-api.com/` на User-PC даёт **HTTP 401**, т. е. API существует, но открыт только при авторизации/токене. Токен выдаётся партнёрам. Нет подтверждения, что конкретный Mobland или желаемые студии доступны. https://github.com/YaNesyTortiK/AnimeParsers/blob/main/KODIK_API.md.
6. **Collaps** — известный видеобалансер с озвучками, iframe, поиском по ID. В современных интеграциях для API требуется токен. Без официальных условий и доступа не считать бесплатной plug-and-play заменой. https://wiki.alcopa.cc/docs/admin/balancers/.
7. **pleer.video** — https://pleer.video/ — заявляет интеграцию без регистрации/токена, iframe и выбор S/E `?season=6&episode=16`, требует **ID Кинопоиска**. На User-PC DNS для хоста **таймаут**, web.open возвращает 502: статус **не подтверждён / ненадёжно** на дату проверки. Проверять позже, не внедрять вслепую.

## Приоритет
- **Сейчас: оставить Initem β основным**, диагностировать его восстановление. Новый домен принимать только из подтверждённых официальных источников — не брать случайные «зеркала».
- **Отдельный технический тест, ничего не публикуя:** APIPlayer (iframe IMDb/S/E — быстро), затем конкретный форк/хост KinoBox (но остерегаться нерабочего kinobox.tv) и Kodik при получении партнёрского токена.
- **Сильные русские озвучки:** Vibix / Kodik / Alloha / Collaps потенциально ближе к желаемой функции выбора студии, но часто требуют токен, партнёрство, рекламу; наличие LostFilm и право использования не подтверждены.
- Для личного Ultra TV избегать ресурсоёмких локальных прокси и headless парсеров на приставке. Добавить отдельный резервный источник только после проверки iframe в KION с пультом, показом нужных серий и русской озвучки.
- Проверять права на встраивание и условия показа контента; поддержка iframe технически не означает наличие лицензии на видео. Не сохранять чужие токены в клиентском JS.
- **Важное:** никаких автоматических переходов на альтернативный сериал/озвучку при сбое, чтобы не подменить предпочтения пользователя без выбора.
