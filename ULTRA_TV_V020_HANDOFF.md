## Решения и требования пользователя к v0.20
1. **Дизайн всего ТВ-приложения:** уйти от насыщенного синего к тёмной **серо-графитовой** палитре по **третьему** из показанных концептов; мягкие серебристо-графитовые тени, не золото и не ярко-голубой/фиолетовый неон. Сдержанная, дорогая тёмная эстетика. Космический мотив допустим в более графитовом исполнении. **Оригинальный логотип U нельзя менять ни рисунком, ни цветом, ни файлом** — пользователь решит отдельно позднее. Боковая панель постоянная, узкая, только иконки, без раскрытия, полупрозрачная, без вертикальной светящейся границы.
2. **Снимите все обычные видимые обводки у постеров/кнопок/иконок.** Фокус пульта должен оставаться отлично виден: небольшой scale ~1.03, мягкая, широкая **нейтральная графитово-серебристая тень ПОЗАДИ выбранной карточки**, допускается под соседними (но не поверх них); никаких голубых рамок. Не использовать дорогой CSS backdrop-filter / тяжёлый blur в циклических анимациях. Для меню — мягкая дымчатая подложка без рамки.
3. **Исправить шестерёнку** (текущая SVG уродлива): новый ровный простой значок в едином наборе с домиком, каталогом, искрой, лупой. Не менять назначения существующих разделов. Для AI-раздела лишь предусмотреть возможность расширения в будущем, **сейчас не создавать**.
4. **Поиск:** при клике на лупу фокус остаётся на её значке, а не перемещается сам в поле; вправо — поле, влево — назад на **лупу**. Сделать строку современнее и компактнее, сохранить ввод экранной клавиатурой приставки.
5. **Левая навигация:** на нажатие ← от левого края карточек, от любой вертикальной позиции на странице, переходить **на иконку текущего раздела** (`S.page`), а не на ближайшую по высоте; при нажатии → из иконки — возврат к последней выделенной карточке/контролу раздела, где возможно. Между карточками ← по-прежнему работает штатно.
6. **Возврат к началу страницы:** сейчас после прокрутки вниз и обратно вверх в каждом разделе заголовок и вводный текст остаются скрыты. Достижение верхнего ряда при движении вверх должно возвращать `scrollY = 0` без насильственной прокрутки при каждом шаге и без потери текущего фокуса. Тест во всех разделах.
7. **Дубли русских названий на постерах в 'Сериалы с высоким рейтингом' (раздел Новинки / сетка) и подобных сетках:** внутри картинки внизу показывается дублированная синяя полоска с русским названием, а под постером уже есть нормальный заголовок. Убрать **только .poster-name внутри картинки** у карточек, имеющих .card-title под постером; сохранить подписи, рейтинг, год, качественные пропорции обложек, не обрезать лица.
8. **Новая карусель 'Продолжить просмотр' на Главной:** фокус ВСЕГДА на центральном постере/карточке; выбранная центральная примерно на 30–40% крупнее боковых, боковые уходят за экран. При ←/→ карточки сдвигаются как колесо и следующая занимает центр, без перемещения фокуса по экрану. Карусель может прокручиваться через активный индекс (не дублировать сериалы при 1–2 элементах). Управление: **↑ из центральной карточки → иконка 'Главная'**; ↓ → 'Мои сериалы'; ← из первой плитки сетки → 'Главная'; → из иконки 'Главная' → возвращаемся к выбранному центру карусели. ОК запускает сериал. Не менять сохранённые прогрессы/серии, сортировку.
9. **Производительность:** слабая KION ТВ-приставка, у v0.18–0.19 субъективные подлагивания. Минимальные анимации, CSS transform/opacity, никаких blur тяжёлых подложек, не увеличивать постоянную нагрузку. Тестировать на десктопном браузере и затем только в подписанной тестовой версии на ТВ.
10. Ещё не вошли в этот этап: синхронизация каталога и времени между сайтом/ТВ, сложная реклама и VPN, объединение описания/плеера и переключение озвучек — **сохранить в общем бэклоге, не мешать задачам v0.20**.

## Известные причины и места кода v0.19
- `tv.js:122-133` `navigate(page,key)`: для `search` выбирается `[data-focus="search-field"]` и вызывается `.focus()`. Для новой логики нужно оставить фокус на `#nav .nav-active` (кроме detail/player), потом вручную пускать вправо в поле.
- `tv.js:158-167` `thumb()` добавляет внутри изображения `<span class="poster-name">` **и** `card()` добавляет отдельный `<span class="card-title">` (двойной русский заголовок). Удалить или скрыть дублирование аккуратно.
- `tv.js:189-193` `rail()` и `174-188` `resumeCard()`; `235-244` `home()`. Карусель менять здесь/в изолированной логике и CSS. Учесть отсутствие history и 1–2 сериала.
- `tv.js:653-718` `buildFocusRows()`; `743-803` `moveFocus()`: сейчас уход в nav при ArrowLeft первого элемента выбирает `nearestFocusY(from, nav.items)` — ошибка, должен быть `nav[data-nav=S.page]`. Сейчас `↑` из `home:rail:0` = null, и `→` из nav отправляет на начало контента. Вернуть по последнему фокусу и отдельным правилам для карусели.
- `tv.js:804-820` `bringFocusedIntoView()`: делает только `scrollBy` до видимой области карточки и не возвращает начало страницы вверху; `.topbar` больше нет с v0.19.
- `tv.css` содержит CSS версий 0.17/0.18 и v0.19, в том числе старые `border` / `:focus`, `box-shadow`. Пересмотреть стили, фокус не терять.
- `tv.html` содержит постоянное меню, оригинальный `/uvideo-tv-logo.png`. ЭТО ИЗОБРАЖЕНИЕ НЕ МЕНЯТЬ.
