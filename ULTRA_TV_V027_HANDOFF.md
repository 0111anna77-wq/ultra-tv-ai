# Ultra TV 0.27 — экран сериала, восстановление работоспособности после переполнения чата

## База и назначение (20 ноября 2026)
- Пользователь показал экран сериала на KION и попросил убрать голубые обводки и лишние линии, привести все элементы к одному левому краю, сделать белые надписи на метках жанров (сами метки сохранить), убрать верхний текст «Ultra TV · сериал» и ручной блок изменения сезонов/серий.
- Вместо S01E01 пользователь просит понятный автоматический статус **«Сезон 1 · Серия 2 · Время 2:50 / 35:00»**. Если время не прислано плеером, не придумывать: «Время пока не получено». Без истории просмотра не придумывать номера сезонов/серий: показывать тире.
- На кнопке **«Назад» пульта из экрана сериала** переходить прямо на **Главную Ultra TV** (не в раздел «Сериалы»). Из плеера первый Back возвращает в экран сериала; второй Back — на главную. Нативная схема вызова `window.UltraTVRemote.back=goBack` осталась.
- Не менять действующий плеер Initem, его механизмы прогресса и выбора серии, сохранённые данные, карусель, сетку и новый лого/баннер 0.26. Озвучка через собственный UI пока не реализована, не обещать поддержку до инженерных тестов.

## Исходники и сборка
- База исходников: GitHub `feature/ultra-tv-v026-fullbleed-kion-logo`, v0.26.
- Рабочая ветка: **`feature/ultra-tv-v027-clean-series-detail`**, исходники коммит `ac94ae5d917c7777e2d13e5bd0e516cfef8f8a67`.
- ПК: `D:\UltraTVTools\uvideo-tv-v027-work\source\android-tv`, тест `D:\UltraTVTools\uvideo-tv-v027-work\check-ui-v027.cjs`, скриншот `D:\UltraTVTools\uvideo-tv-v027-work\preview-detail-v027.png`.
- Изменения только в `app/src/main/assets/tv.js`, `tv.css`, `tv.html` и `app/build.gradle` (versionCode 27, versionName 0.27-tv-detail-cleanup). Остальные картинки, логотип U и KION banner полностью сохранены.
- `detail()` возвращает компактную страницу: постер без рамки, заголовок, метаданные, светлые жанровые бейджи, описание, кнопки «Смотреть/Продолжить», коллекция, **«Источники»**, автоматически считываемые номер сезона, серии и время.
- `progressUI(x)` теперь только **read-only**. Никаких ручных кнопок +/- и «Сохранить», кнопки «Изменить» также нет. Не изменяет хранилище `tv-progress-v1`. Для ранее вручную выбранных серий честная подпись «Серия выбрана вручную ранее», для автоматически подтверждённых Initem — «Определено плеером», иначе не приписывает плееру неподтверждённую информацию.
- Статус просмотра без прямоугольной рамки, на той же линии: «Сезон N · Серия N · Время M:SS / HH:MM». Кнопки с графитово-сливовым мягким фокусом, нет ярко-голубых рамок. Метки жанров сохранили форму, текст почти белый.
- `goBack()`: при S.page==='detail' вызов `navigate('home')`. Кнопка меню «домик» активна в экране серии и плеера.
- Для источников оставлена реальная поддержка переключения поставщика в существующем коде; кнопка не утверждает, что интерфейс уже умеет переключать дубляж. Подробное сообщение в разворачивающейся панели источников.
- Поле источника под строкой прогресса убрано как дублирующее: список показывается по кнопке «Источники».
