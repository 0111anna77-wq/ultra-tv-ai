# Ultra TV 0.27 — карточка сериала, сохранённый прогресс и возврат на главную

Дата: 20 ноября 2026. Работа продолжена от **v0.26** (`feature/ultra-tv-v026-fullbleed-kion-logo`), без отката баннера и логотипа.

## Запрос пользователя
Скриншот открытой вкладки «Неуязвимый»: ненужные голубые рамки вокруг постера, кнопок и старой широкой панели с плюс/минус; бесполезная надпись «Ultra TV · сериал»; основной экран неаккуратно выровнен; пользователь хочет видеть сохранённые автоматически сезон/серию, а не менять их каждый раз вручную. Надо оставить возможность исправить вручную как запасной вариант. Озвучку пока выбирают внутри Initem, но нужен понятный пункт в интерфейсе. Кнопка **«Назад» из карточки сериала должна сразу вести на главную**, а не во вторую вкладку «Сериалы».

## Реализовано локально
- База `D:\UltraTVTools\uvideo-tv-v027-work\source\android-tv`; основные изменения только в `app/src/main/assets/tv.js`, `tv.css`, `tv.html` и `app/build.gradle`.
- `detail()`: убран «Ultra TV · сериал», постер без границы, контент выровнен по верхнему краю постера; кнопка «Смотреть / Продолжить просмотр» в графитово-сливовом цвете, сохранение в каталог, «Источник и озвучка».
- `progressUI()`: компактная ненавязчивая панель «Последний просмотр» показывает сохранённые сезон, серию, время, если они были. Источник данных `S.progress / tv-progress-v1` (в Initem автоматически пишет `handleInitemMessage`; если данных нет — явно «пока не определены»). Не притворяться, что Initem гарантирует автоматический переход на секунду — это **отдельная будущая задача**.
- `S.progressEditOpen`, кнопка **«Изменить»**: только по явному нажатию появляются существовавшие сезон/серия плюс/минус и «Сохранить». Все прежние записи и fallback сохранены.
- Кнопка «Источник и озвучка» открывает те же варианты источников, что и раньше, но честно пишет, что дорожку озвучки пока выбирают *в самом плеере* — полноценного API управления голосами ещё нет. Действие `preselect-source` сохранено.
- `openShow()` теперь выставляет сезон/серию/источник из ранее сохранённого прогресса для правильного выбора поставщика, до начала воспроизведения.
- `goBack()`: `detail -> home`, а не `detail -> catalog`. Native Android `UltraTvActivity.onBackPressed()` уже вызывает `window.UltraTVRemote.back()`, так что этот маршрут работает и с аппаратной кнопки. Из `player` по-прежнему выход в `detail` (не менять без отдельного запроса пользователя); следующий Back из `detail` возвращает домой. Подсветка меню для `detail/player` теперь соответствует иконке «домик», а не второй вкладке.
- Цветовые переопределения `.detail-v027` в конце CSS полностью локализованы на экране подробностей: нет новых запросов/динамического blur, форма построена на лёгком flex/grid + статичной тени.
- `tv.html`: `tv.css?v=27`, `tv.js?v=27`; Gradle versionCode **27** / versionName `0.27-tv-detail-cleanup`. Размеры и данные других страниц не менялись, сам `sourceMedia()`, iframe, `handleInitemMessage()` и логотип не переписывались.
