# Ultra TV · Sport Lab (изолированный прототип)

**Этот модуль не подключён к \`index.html\`, \`player.js\` или Android APK.**
Открывается отдельно по \`/sport-lab/\`. До слияния PR рабочий сайт не меняется.

## Что уже реализовано

- Лёгкая TV-friendly страница без сборщика и внешних JS-библиотек: поиск команд и каналов, вкладки, избранное в localStorage, навигация фокусом с пульта.
- Каталог 10 российских платных спортивных телеканалов (бесплатный «Матч ТВ» специально исключён).
- Футбольный календарь на ~3 недели из публичного CC0 OpenFootball: АПЛ, Ла Лига, Бундеслига, Серия А, Лига 1.
- **Программа передач «Старт» на 4 дня**: импортируется с официальной страницы, выделяются футбольные события, московское время и отметка «Прямой эфир». Это НЕ прямой видеопоток и НЕ подтверждение бесплатного доступа.
- Серверное обновление через Python + GitHub Actions (после слияния PR в default branch): страница читает **один небольшой статический JSON** без сканирования сотен ссылок с ТВ.
- Подготовленная схема \`broadcasts.json\` для точного сопоставления матча, канала, русской дорожки, статуса доступа и официальной ссылки.
- Неизвестное время начала, неизвестный вещатель и неподтверждённый русский звук **не называются проверенными**.

## Что ещё не реализовано

- Для «Старт» добавлен импорт публичной телепрограммы. Автоматическое определение вещателя для матчей остальных телеканалов пока отсутствует: желательно получить документированный API/EPG с корректными условиями использования.
- Проверка действующих тарифов Иви/Okko/KION: статус в стандартных пакетах пока **неизвестен**.
- Найденные/проверенные доступные видеотрансляции: 0. Встраивание платных защищённых каналов и обход DRM не выполняются.
- РПЛ, Кубок России и еврокубки: в нынешней открытой базе 2026/27 этих турниров нет. Дополним отдельными источниками расписания.
- Фактические тесты на конкретной МТС-приставке.

## Модель данных

\`channels.json\` — список каналов + официальные страницы телепрограмм;
\`data.json\` — кеш ближайших матчей;
\`broadcasts.json\` — **только подтверждённые** эфиры (пока пусто).

Пример будущей записи \`broadcasts.json\` (не добавлять без реальной проверки):

\`\`\`json
{"fixtureId":"en.1-123","channelId":"match-football-1","commentary":"ru",
 "access":"subscription","watchUrl":"","verifiedAt":null}
\`\`\`

Для бесплатного эфира допустимо \`access: "free"\` только при наличии разрешённой официальной страницы, даты проверки и подтверждения русской речи. В интерфейсе кнопка воспроизведения показывается только для проверенного бесплатного эфира и только если URL входит в разрешённый список официальных доменов.

## Обновление

\`\`\`sh
python3 sport-lab/test_update.py
python3 sport-lab/update_sport.py
\`\`\`

Скрипт использует Python 3, только стандартную библиотеку, ходит за метаданными в \`openfootball/football.json\`, не открывает видео. При частичной сетевой ошибке сохраняет кеш соответствующей лиги; при полном отказе не затирает каталог. Если данных нет или они устарели, доверять времени/телепрограмме нельзя.

Workflow \`.github/workflows/sport-discovery.yml\` после вливания в \`main\` обновляет JSON один раз в день и коммитит файл, только если состав данных поменялся.

## Изоляция и производительность

\`sport-lab/app.js\` загружается **только на странице /sport-lab/**. На домашней странице никаких новых запросов, обработчиков и загрузки JS нет. Кнопка ссылки на модуль может быть добавлена позже, когда закончат разработку дизайна. GitHub Actions выполняет сбор данных вне приставки. Cloudflare Pages отдаёт уже подготовленный JSON и HTML.

## Ограничения источника

OpenFootball — CC0: https://github.com/openfootball/football.json .
Открытая база не является официальной телепрограммой: возможны устаревшие даты и ошибочные матчи. Исходные данные намеренно не показывают время начала (часовой пояс не гарантирован). Для вещателей нужно независимое подтверждение из официальных источников, не предположение по названию матча.
